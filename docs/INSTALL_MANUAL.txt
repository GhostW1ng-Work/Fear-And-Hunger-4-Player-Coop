Fear & Hunger Co-op (Termina and Fear & Hunger 1) - install
=============================================================
(Русская инструкция - ниже.)

INSTALL: unpack the archive into the game folder (where Game.exe is) and agree to
replace the files. That's all - start the game.

  The archive has a "www" folder: it goes on top of the game's "www" folder.
  Steam: right click the game > Manage > Browse local files.

PLAY: on the map press X (or Start on a gamepad) - player 2 joins; U / Numpad 0 or
Start on another gamepad - the next one. The rest is in README.md; online play:
docs\NETPLAY.md.

UPDATE: unpack the new version the same way, replacing the files.

REMOVE: delete these files from www\js\plugins: LookOutsideOnline.js,
LocalCoop_FearHunger.js, LocalCoop_Net.js (the game starts as usual without them).
To put back the game's own www\js\main.js too: Steam > the game > Properties >
Installed files > Verify integrity of game files.

How it works: the mod's www\js\main.js is the game's own one plus a few lines that add
the co-op plugins after the game's plugins. The game's plugins.js is not changed.

The same mod with an automatic installer is in the GitHub releases:
https://github.com/GhostW1ng-Work/Fear-And-Hunger-4-Player-Coop/releases


Кооператив для Fear & Hunger (Termina и Fear & Hunger 1) - установка
=====================================================================

УСТАНОВКА: распакуйте архив в папку игры (где лежит Game.exe) и согласитесь заменить
файлы. Всё - запускайте игру.

  В архиве папка "www": она ложится поверх папки "www" игры.
  Steam: правой кнопкой по игре > Управление > Просмотреть локальные файлы.

ИГРА: на карте нажмите X (или Start на геймпаде) - войдёт второй игрок; U / Numpad 0
или Start на другом геймпаде - следующий. Остальное - в README.ru.md; игра по сети -
docs\NETPLAY.ru.md.

ОБНОВЛЕНИЕ: распакуйте новую версию так же, с заменой файлов.

УДАЛЕНИЕ: удалите из www\js\plugins файлы LookOutsideOnline.js,
LocalCoop_FearHunger.js, LocalCoop_Net.js (без них игра запускается как обычно).
Чтобы вернуть и родной www\js\main.js игры: Steam > игра > Свойства >
Установленные файлы > Проверить целостность файлов игры.

Как это работает: www\js\main.js мода - это родной файл игры плюс несколько строк,
которые подключают плагины кооператива после плагинов игры. plugins.js игры не меняется.

Тот же мод с автоматическим установщиком - в релизах на GitHub:
https://github.com/GhostW1ng-Work/Fear-And-Hunger-4-Player-Coop/releases
