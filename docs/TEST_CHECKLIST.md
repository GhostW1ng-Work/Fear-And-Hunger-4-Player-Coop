# Чек-лист проверки кооп-мода (Fear & Hunger 1 и Termina)

Как пользоваться: ставьте `[x]` в квадратных скобках, если всё работает, и `[!]`, если нашли баг.
Если что-то сломалось, пишите заметку прямо под пунктом: где, что делали, что произошло.
Буквы в скобках: **(FH1)** — только Fear & Hunger 1, **(T)** — только Termina, **(Сеть)** — только сетевая игра.

Если в сетевой игре что-то пошло не так, сохраните файлы из папки `www` игры на **всех** ПК:
`coop_net_desync.log`, `coop_net_error.log`, `coop_net_battle.log`.

Версия мода, которую проверяю: ______ Дата: ______

## 0. Подготовка

- [ ] В каждой копии игры одна и та же версия мода (в Options → Co-op видна версия)
- [ ] Есть сохранения: начало игры, середина, место у кровати или точки сохранения, место рядом с врагами
- [ ] Для теста по сети на одном ПК: в каждой копии *Co-op settings → Local co-op: Off* (чтобы клавиатура не путалась)

## 1. Установка

- [ ] `install.bat`, распакованный прямо в папку игры, ставит мод туда без вопросов
- [ ] `install.bat` из другой папки сам находит игру (Steam / GOG / папка Games) и показывает список с версиями
- [ ] Выбор нескольких игр (`1,3`) и `A` (все) работают
- [ ] Если перетащить папку игры на `install.bat`, мод ставится в неё
- [ ] Повторный запуск обновляет мод, игра запускается
- [ ] `-Uninstall` убирает мод, игра запускается как оригинал
- [ ] При запуске нет ошибок; на титульном экране есть **Host online / Join online**
- [ ] Если вышла новая версия, на титульном экране появляется надпись об обновлении

## 2. Локальный кооп: вход игроков и управление

- [ ] P2 входит по `X` на карте (стрелки — движение, Enter — действие, Backspace — меню)
- [ ] P3 входит с клавиатуры (`U` / `Numpad 0`) и ходит нумпадом или IJKL
- [ ] Геймпад: `Start` добавляет следующего игрока, и геймпад закрепляется за ним
- [ ] Свободный геймпад управляет P1
- [ ] Если отключить геймпад, игрок «отошёл»: за него играет AI, на карте он идёт за P1. Кнопка геймпада возвращает его
- [ ] Бег (Shift / X / RT) у каждого игрока свой
- [ ] Нумпад работает и с NumLock, и без

## 3. Камера и сплит-скрин

- [ ] Auto: камера общая, пока все рядом, и делится, когда кто-то уходит; общая снова, когда все вместе
- [ ] `G` переключает: auto / shared / split / P1..P4
- [ ] Сплит на 2, 3 и 4 игроков выглядит правильно, ничего не дёргается
- [ ] `-` / `=` отдаляют и приближают вид в сплите
- [ ] **F9** открывает окна игроков: у каждого свой вид (экспериментально)

## 4. Выбор персонажей и состав отряда

- [ ] Новый игрок выбирает персонажа из списка (классы и спутники)
- [ ] Номер места в отряде = номер игрока
- [ ] Хост в меню **Co-op** выбирает, кто управляет дополнительными персонажами в бою (P1..P4 / AI)
- [ ] «Отметить отошедшим» и «забрать персонажа» в Co-op работают
- [ ] Ждущему игроку можно дать свободного персонажа (`< Pn >`)
- [ ] *Keep players' characters: On*: если сюжет убирает персонажа игрока, тот остаётся
- [ ] (T) В одиночных частях сюжета игроки ждут, а потом возвращаются сами
- [ ] (T) Когда игра переставляет отряд, каждый остаётся при своём персонаже

## 5. События и диалоги

- [ ] P2 заговорил с NPC: варианты ответа выбирает P2, на экране «P2 CHOOSES»
- [ ] P2 осмотрел предмет или сундук: всё происходит у P2 (позиция, направление)
- [ ] Предмет из меню P2 (еда, лечение, факел) действует от его имени
- [ ] Ловушки и загадки, которые запустил P2, срабатывают на P2
- [ ] Сцена, которая ведёт P1 далеко (3+ клетки), уводит за ним остальных. После сцены никто не застревает в стене
- [ ] Двери и проёмы: P2 **не** тянется за P1 сам по себе
- [ ] Если персонаж всё-таки оказался в стене, его ставит рядом с P1

## 6. Меню игроков

- [ ] P2–P4 открывают своё меню: Skill / Equip / Status сразу на своём персонаже
- [ ] Options, Save, Game End, Formation есть только у P1
- [ ] В меню отвечают только клавиши его хозяина
- [ ] Предмет из меню P2 тратится и действует правильно

## 7. Бои (локально)

- [ ] Каждый ходит своим персонажем, сверху видно, чей ход
- [ ] Дополнительные персонажи ходят по выбору в Co-op (игрок или AI)
- [ ] Части тела врагов (FH1) выбираются правильно и стрелками, и OK
- [ ] Побег, победа, поражение работают как в игре
- [ ] Конец боя: никто не остаётся с лишним ходом, меню не зависает

## 8. Смерть и воскрешение

- [ ] Смерть P2–P4 **не** заканчивает игру (*When P2-P4 die: The party goes on*)
- [ ] Тело лежит там, где персонаж умер, видно имя «+ Имя»
- [ ] Ушли с карты и вернулись: тело на том же месте (и его можно воскресить)
- [ ] (FH1) Тело — это труп самой игры; без заполненного камня работают её варианты, например поймать душу пустым Soul stone
- [ ] Заполненный камень + OK у тела → «вернуть?» → персонаж вернулся с 30% HP и рассудка, камень потрачен
- [ ] Тот, кто воскресил, потерял 30% рассудка
- [ ] После воскрешения тело и надпись исчезают сразу; на других картах тела тоже нет
- [ ] (FH1) Погибший спутник не встречается потом «живым» NPC в мире; после воскрешения игра считает его живым
- [ ] Настройки *Revived with* / *Mind cost of reviving* меняют проценты
- [ ] *When P2-P4 die: Game over* — смерть любого игрока заканчивает игру
- [ ] Смерть P1 — конец игры (как в оригинале)
- [ ] Погибший игрок может получить свободного персонажа через Co-op
- [ ] *Revive with soul stones: Off* — тела для воскрешения нет, игрок ждёт; включили обратно — уже лежащие тела снова можно воскресить

## 9. Факелы и свет

- [ ] (FH1) P2 зажёг факел из своего меню: светит вокруг P2, факел в руке у P2
- [ ] (FH1) Факел P1 и факел P2 горят одновременно и гаснут каждый сам
- [ ] (FH1) Факел P2 догорел: надпись «…'s torch died down», факела в руке больше нет
- [ ] (FH1) Новый факел, пока горит старый, продлевает его
- [ ] (T) Свет вокруг каждого игрока в тёмных помещениях, и у клиента далеко от P1
- [ ] (T) Круг видимости (тёмный слой) у каждого ПК вокруг своего персонажа
- [ ] (Сеть) Камера клиента правее или ниже P1: свет P1 остаётся на месте, вокруг P2 тоже светло

## 10. Двойники NPC (персонаж игрока не стоит на карте ещё и NPC)

- [ ] (FH1) P2 играет Наёмником (Кахарой): его нет в камере, в Махабре, в тюрьме
- [ ] (FH1) То же для Рыцаря (Д'арс), Тёмного жреца (Энки), Чужеземца (Рагнвальдр), Moonless
- [ ] (FH1) Ле'гард: что остаётся, что пропадает (записать)
- [ ] (T) P2 играет Оливией, Мариной, Дааном, Абеллой, О'саа и др.: их нет в поезде и рядом с ним
- [ ] (T) Карин, Маркох, Леви, Калев — их места в городе
- [ ] Отдали персонажа (он ушёл из отряда) → NPC вернулся
- [ ] *Played characters' NPCs: Shown* → NPC снова стоят, как в игре
- [ ] Сюжет с этим персонажем не ломается (диалоги, найм другими путями)

## 11. Читы (*Cheats: On*)

- [ ] F6 / F7 сохраняют и загружают где угодно; при *Cheats: Off* не работают (надпись)
- [ ] Co-op → получить камень душ
- [ ] Co-op → восстановить HP, рассудок, голод всего отряда
- [ ] Co-op → получить факелы и огонь (Torch x3 + Tinderbox / Matches / Lighter)
- [ ] *Immortal party*: отряд не падает ниже 1 HP
- [ ] *Keep limbs*: руки, ноги и голову не отрубают
- [ ] *One-hit kills*: любой урон сразу убивает врага или часть врага
- [ ] *Open locks*: двери, сундуки, камеры с ключом или отмычкой открываются

## 12. Сохранение и загрузка

- [ ] Сохранение помнит, кто играл и каким геймпадом; после загрузки все возвращаются сами
- [ ] Тела, факелы игроков и скрытые NPC правильные после загрузки
- [ ] Загрузка сохранения без кооператива работает как обычно

## 13. Сеть: подключение

- [ ] (Сеть) **Host online** → выбрать сохранение → игра открыта, виден IP
- [ ] (Сеть) **Join online** → игра хоста видна в *Games found* → подключение
- [ ] (Сеть) Подключение по IP вручную (в том числе через Radmin / ZeroTier)
- [ ] (Сеть) Пароль: с неверным не пускает, с верным пускает
- [ ] (Сеть) Разные версии мода или игры: не пускает и пишет, что именно отличается
- [ ] (Сеть) Лобби: список игроков, **I'm ready**, отсчёт 3 с, старт сам; **Start now** у хоста
- [ ] (Сеть) *Bring character*: гость приходит со своим героем из сохранения (уровень, снаряжение)
- [ ] (Сеть) Пинг вверху справа и в лобби; *Ping on screen* выключает его
- [ ] (Сеть) Через интернет с реальным пингом игра идёт ровно (delay: auto)

## 14. Сеть: игра

- [ ] (Сеть) Меню одного игрока не останавливает других
- [ ] (Сеть) У каждого камера на своём персонаже
- [ ] (Сеть) Опции игры (Always Dash и т.п.) у всех как у хоста; громкость у каждого своя
- [ ] (Сеть) Мышь не влияет на игру
- [ ] (Сеть) F6 / F7 работают только у хоста; F7 — все на секунду на титул, потом игра продолжается
- [ ] (Сеть) Строка **Cheats** в меню сети: хост переключает её во время игры, у всех надпись
- [ ] (Сеть) Строка **Played chars' NPCs**: переключается во время игры для всех
- [ ] (Сеть) Долгая игра (1+ час): нет «PCs out of sync», нет резких скачков пинга

## 15. Сеть: бои

- [ ] (Сеть) *Battles: Together* — все в бою вместе, как в локальном коопе
- [ ] (Сеть) *Battles: Separate* — в бою только тот, кого задел враг, остальные ходят по карте
- [ ] (Сеть) Войти в чужой бой: OK рядом с дерущимся или коснуться врага; вход со следующего хода
- [ ] (Сеть) Выбор врага или части врага одинаковый у всех (нет рассинхрона после атаки)
- [ ] (Сеть) Пока кто-то в бою, остальные **не могут** пройти в дверь, лечь спать, сохраниться (надпись «Px is fighting here»)
- [ ] (Сеть) После боя всё это снова доступно
- [ ] (Сеть) (FH1) Проигранный отдельный бой без P1: сцены поражения (стражи, кровавая яма) **не** запускаются у всех, бойцы — тела
- [ ] (Сеть) Отдельный бой, где все бойцы умерли, не затягивает персонажа P1
- [ ] (Сеть) P2 в бою с одним врагом, P1 касается другого — у P1 свой бой, оба идут одновременно
- [ ] (Сеть) Один из двух боёв выигран — второй продолжается как обычно (не «побеждает сам», не вылетает)
- [ ] (Сеть) Победивший приходит на помощь: OK рядом с дерущимся — входит в его бой
- [ ] (Сеть) Один проиграл свой бой — у второго бой продолжается

## 16. Сеть: отключения

- [ ] (Сеть) Гость закрыл игру или отключился: у остальных игра идёт, его персонаж идёт за P1; в бою им управляет хост или следующий боец
- [ ] (Сеть) Гость вернулся посреди игры: получает своего персонажа обратно
- [ ] (Сеть) Новый гость входит посреди игры: получает следующий номер
- [ ] (Сеть) Хост нажал Stop: у всех меню работает (курсор ходит, можно выйти в титул)
- [ ] (Сеть) Гость нажал Disconnect: у него меню работает
- [ ] (Сеть) Хост вышел и снова открыл игру: гость переподключается и снова P2
- [ ] (Сеть) Отключение во время отдельного боя: его бой сразу заканчивается побегом, игра не виснет
- [ ] (Сеть) Свернуть окно клиента на 10+ секунд: хост играет дальше, клиента не выкидывает; развернул — догоняет
- [ ] (Сеть) Клиент потерял хоста — уходит на титульный экран и сам переподключается
- [ ] (Сеть) Строка *Revive (soul stones)* в меню сети: хост переключает во время игры, у всех надпись

## 17. Termina: особенности

- [ ] (T) PvP выключен: OK лицом к другому игроку ничего не делает
- [ ] (T) PvP: напасть можно с любой стороны (и по диагонали); если впереди NPC — OK говорит с ним
- [ ] (T) Сзади (соперник смотрит в другую сторону): он пропускает первый ход
- [ ] (T) Бой длится несколько ходов (не убивает с одного удара); *PvP damage* меняет урон
- [ ] (T) Отрубили ногу — в голову легко попасть; руку — бьёт слабее; обе руки — почти без урона
- [ ] (T) Конечности, потерянные до боя, у врага с начала отсутствуют
- [ ] (T) *Run* — бой кончается для обоих, здоровье и состояния сохраняются
- [ ] (T) Насмерть: убит P1 (главный герой) — конец игры
- [ ] (T) PvP не насмерть: OK лицом к игроку → «Attack ...?» → бой против его персонажа (его картинка с частями тела)
- [ ] (T) Атакованный сам выбирает свои ходы и бьёт нападающего, выбирая часть тела
- [ ] (T) (Сеть) У каждого на экране враг — другой игрок, а в отряде только свой персонаж; меню соперника в его ход не видно
- [ ] (T) Отрубили руку / ногу противника — у его персонажа Arm cut / Leg cut
- [ ] (T) Не насмерть: дошёл до 0 — остаётся 1 HP, бой закончился; отрубленное в бою вернулось
- [ ] (T) Насмерть: проигравший погиб, лежит тело, можно воскресить камнем
- [ ] (T) (Сеть) PvP с отдельными боями: атакованный входит в бой нападающего, у обоих свой экран боя

- [ ] (T) P2–P4 стреляют на карте (оружие экипировано + бег)
- [ ] (T) Враги идут к ближайшему игроку
- [ ] (T) Поезд: сцены, ожидающие спутники, переходы между днями
- [ ] (T) Одиночные части сюжета: остальные ждут и возвращаются
- [ ] (T) Сцены, где P1 прячется или исчезает: P2–P4 тоже
- [ ] (T) Ночь, закат, туман — видимость у каждого игрока правильная

## 18. Fear & Hunger 1: особенности

- [ ] (FH1) P2–P4 стреляют из лука (Short bow / Cursed short bow + стрелы)
- [ ] (FH1) В выборе персонажа есть четыре класса и спутники (Le'garde, Moonless, Nas'hrah)
- [ ] (FH1) Найм спутников по сюжету работает, если такой персонаж уже есть у игрока
- [ ] (FH1) Голод, рассудок, отрубленные конечности у каждого персонажа свои
- [ ] (FH1) Камни душ: заполнить пустой, использовать заполненный
- [ ] (FH1) Ловушки (ямы, капканы), которые задел P2, срабатывают на P2

- [ ] Загрузка сохранения после прохождения работает
